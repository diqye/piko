piko

About

piko is a capsule built for pi code agent. It shows agent status (idle / thinking / working) as a floating, always-on-top window. Compatible with Claude Code.

Why

  • pi code agent runs in the terminal — you switch windows to check progress
  • Want a tiny floating window that tells you what the agent is doing at a glance
  • Minimal, fast, and quiet — never gets in the way of your main work
